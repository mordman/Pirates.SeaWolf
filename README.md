# Pirates.SeaWolf

Морская 3D-песочница о парусниках: Explore/Sail/Trade/Fight на движке three.js внутри Next.js.

## Что внутри

- **Корабли**: процедурная сборка корпуса и рангоута (30+ пресетов), парусное вооружение — кливера, топселя, латинские паруса, флаги; плавучесть и дифферент по волне.
- **Море и мир**: квадраты моря со сменой погоды, острова, фольклорные команды, плавающий мусор и рыбалка.
- **Бой**: пушки с типами снарядов, пробитие бортов по локальной стороне (сквозной разрыв при sideOpen ≥ 45%), целостность киля и перелом корабля пополам, абордажи, подзорная труба.
- **Капитан-игрок (lander)**: выход на сушу, оружие в руках, режим подзорной трубы с зумом 2×–8×.
- **Квесты**: выбор «Жемчужины» и проклятый капитан-мертвец с зелёной саблей, шхуна «Жемчужина» и её команда.

## Запуск

```bash
npm install
npm run dev
# открыть http://localhost:3000
```

Требуется Node.js 18+.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/game/` | Ядро игры: корабли (`ship/`), мир (`world/`), вода (`water/`), бой (`combat/`), аудио, камера, лоцмен-капитан (`player/lander.ts`) |
| `src/app/` | Страница Next.js, хостящая canvas игры |
| `scripts/` | E2E-прогоны (`e2e_v*.mjs`) и отладочные/аудит-скрипты задач |
| `AGENTS.md` | Память проекта для LLM-агентов: карта кода, сводка задач 1–80, e2e-система, соглашения, подводные камни |
| `worklog.md` | Полный журнал задач: что и почему сделано |
| `skills/` | SKILL.md-инструкции среды (документы, изображения, e2e-браузер, диагностика) |
| `tests/` | Тесты |
| `download/` | Артефакты задач: скриншоты, логи прогонов |

## Разработка

```bash
npm run lint   # ESLint
npm run build  # production-сборка
```

Регрессионные прогоны выполняются скриптами `scripts/e2e_v*.mjs` (управление через `z-ai`/agent-browser): открывают игру, проходят сценарии и сверяют состояние через `window.__game`.

Если вы — LLM-агент, продолжающий разработку: начните с [AGENTS.md](AGENTS.md) — там собраны память задач 1–80, карта кода, регрессионная система и соглашения проекта.
